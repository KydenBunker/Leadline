YOUR WORKSPACE

Settings & sync.

Customize both workspaces, install the app, and keep your data backed up.

Weekly target

Choose the appointment goal you want to see on your dashboard.

Designer pay estimates

Optional settings for your own planning, not a statement about overtime eligibility or your actual paycheck.

Weekly estimates start Monday. Settings are synced to your account when cloud sync is configured. Actual overtime rules can differ, including by state, workweek, age, or job classification.

Install Leadline

Make it feel like a real app, with its own icon and a standalone window.

Install requires the website to be opened over HTTPS (or localhost). On Android Chrome, use the browser menu → “Install app” or “Add to Home screen.”

Export & restore

Back up both appointments and your design timesheets even if you use cloud sync.

Imported records will be merged by ID when available. New CSV entries get new IDs.

Cloud sync

Sync appointments and designer hours between your phone and Mac

Not connected

Optional: the app works offline without this. To enable sync, create a free Supabase project and run the included supabase-setup.sql (even if you used v2). Your records stay private to your signed-in account under database access rules.

Signed in as

Add your Supabase details, then sign in with the same account on both devices.

Don't paste a Supabase secret or service_role key here. Cloud sync requires an internet connection; offline changes sync later. If two devices edit the same entry before syncing, the most recent edit wins.

Clear local data

Remove appointments and designer hours stored in this browser. If cloud sync is enabled, use sign out first; otherwise cloud records may be re-downloaded.
